# Four-language benchmark results — 2026-11-24

## Result

A same-runner benchmark compared C, C++, Rust and CPython using the same deterministic Conway's Game of Life workload. All implementations produced the exact same final-state checksum.

| Language | Median kernel time | Cell updates/s | Relative time vs fastest |
|---|---:|---:|---:|
| Rust | 9.169 ms | 571,777,183 | 1.00x |
| C | 9.707 ms | 540,130,403 | 1.06x |
| C++ | 10.000 ms | 524,312,223 | 1.09x |
| Python | 2,043.594 ms | 2,565,520 | 222.87x |

Shared checksum: 61ba73df36b48d49

## Test environment

- GitHub-hosted Ubuntu Linux runner
- Intel Xeon Platinum 8573C, 4 vCPUs exposed to the job
- GCC C compiler 15.2.0, C17, -O3 -march=native
- GCC C++ compiler 15.2.0, C++23, -O3 -march=native
- rustc 1.100.0, edition 2024, -C opt-level=3 -C target-cpu=native
- CPython 3.15.2
- Grid: 256 x 256; 80 generations; 5,242,880 cell updates
- One warm-up, five timed samples, median reported
- Initialization, process startup, compilation and checksum calculation excluded from kernel timing
- Single-threaded, no external libraries

## Interpretation

On this workload, Rust was about 5.5% faster than C and 9.1% faster than C++. These are relatively small native-code differences and may reverse with another compiler, target, workload or code shape. Python was about 223x slower than the fastest native result.

A first flat-index Rust implementation measured 12.566 ms on a different run. A row-slice version subsequently measured 9.169 ms. This illustrates how implementation details matter; it is not a controlled paired A/B comparison.

This is one microbenchmark, not a universal ranking. It does not measure memory footprint, startup latency, I/O, parallel scaling, vectorized library workloads, application end-to-end performance, or developer productivity. It does not establish that one language is inherently faster in every program.

## Reproduction

Run:

    python benchmarks/four-language/run.py

The script compiles C, C++ and Rust into a temporary directory, runs all implementations, checks matching checksums, and prints raw samples plus medians.
